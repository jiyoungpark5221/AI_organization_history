수집 주기·연결정보

이 시각에 자동으로 실행되도록 서버의 스케줄러(cron, Windows 작업 스케줄러 등)에서 python -m app.daily 를 호출해 등록하세요. 이 값은 등록한 시각을 기록해 두는 용도이며 화면에서 스케줄러를 직접 만들지는 않습니다.

연결 방식 확정 전 시험용 파일 입력입니다. GCC·법제처·내부 LLM의 실제 연결 방식이 확인되면 이 항목이 교체됩니다.

수동 파일 입력 (보조 기능)

연결 장애나 시험 운영 시 GCC 자료 파일을 직접 올립니다. 올린 파일은 GCC 자료 폴더에 날짜.json 으로 저장됩니다.

지금 실행

지정한 날짜의 자료로 수집 → 변경 탐지 → 법령 확보·분석을 한 번 실행합니다. 같은 날짜를 다시 실행해도 같은 변경은 중복 등록되지 않습니다.
